API JSON

Documentația interactivă: /api/docs. Exemple:

  • /api/v1/parlamentari?camera=cd&sort=prezenta
  • /api/v1/parlamentari/{id}
  • /api/v1/proiecte?q=pensii, /api/v1/proiecte/{id}
  • /api/v1/voturi/{id}
